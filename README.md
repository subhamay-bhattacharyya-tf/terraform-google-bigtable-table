A Terraform module for creating and managing a **Google Cloud Bigtable table**.

---

## Overview

This module provisions a single `google_bigtable_table` resource on GCP. It accepts a structured `bigtable_table_config` object variable to configure column families, split keys, deletion protection, change stream retention, and automated backup policies. Table names follow the convention `<project_code>-<base_name>-<environment>`.

---

## Usage

```hcl
module "bigtable_table" {
  source = "github.com/subhamay-bhattacharyya-tf/terraform-google-bigtable-table"

  environment  = "devl"
  project_code = "myapp"
  region       = "us-central1"

  bigtable_table_config = {
    base_name     = "events"
    instance_name = "myapp-bigtable-instance"
    column_family = [
      { family = "cf1" }
    ]
    deletion_protection = "PROTECTED"
  }
}
```

## Notes & Caveats

> **Destructive operation:** Destroying this module will delete the Bigtable table
> and all data within it. Ensure `deletion_protection` is set to `UNPROTECTED`
> before running `terraform destroy`.

- The table name is automatically constructed as `<project_code>-<base_name>-<environment>`.
- A Bigtable instance must already exist before creating a table. This module does not manage instances.
- Change stream retention requires the Bigtable instance to have change streams enabled.
- Automated backup policies require the instance to support automated backups.

## CI / Workload Identity Federation Setup

The Terratest job authenticates to GCP via [Workload Identity Federation](https://cloud.google.com/iam/docs/workload-identity-federation) (service account impersonation). If the job fails with `Permission 'iam.serviceAccounts.getAccessToken' denied`, grant the WIF pool principal the required IAM binding:

```bash
gcloud iam service-accounts add-iam-policy-binding \
    "<service-account-email>" \
    --project="prj-15-cloud-bigtable-16748" \
    --role="roles/iam.workloadIdentityUser" \
    --member="principalSet://iam.googleapis.com/projects/<project-number>/locations/global/workloadIdentityPools/<pool-name>/attribute.repository/subhamay-bhattacharyya-tf/terraform-google-bigtable-table"
```

The three repository variables required by the CI workflow are:

| Variable | Description |
|----------|-------------|
| `GCP_PROJECT_ID` | GCP project ID passed as `GOOGLE_CLOUD_PROJECT` to Terratest |
| `GCP_WORKLOAD_IDENTITY_PROVIDER` | Full WIF provider resource name |
| `GCP_SERVICE_ACCOUNT` | Service account email to impersonate |
